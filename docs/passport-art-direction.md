# BIGCAT Passport — Art direction / คู่มือส่งต่องานภาพ

Updated: 2026-09-16. อ่านไฟล์นี้ก่อนสร้าง/แก้ตรา Passport ทุกครั้ง เพื่อให้เหมือนงานจากคนวาดเดิม

## 1. สถานะการอนุมัติและขอบเขต

- ผู้ใช้ชอบรูปแบบตรา 3D enamel ขอบทองที่ทำไว้: ถือเป็น style anchor ห้ามเปลี่ยนแนวตามใจ
- `public/images/stamps/nobi-enamel-v1.webp`: ต้นแบบวัสดุ/ใบหน้าโนบิ/กรอบ
- `public/images/stamps/boota-enamel-v1.webp`: ต้นแบบวัสดุ/ใบหน้าบูตะ ชุดสูทม่วง เก็บไว้เป็น reference ไม่ลบ
- `public/images/stamps/boota-merit-heaven-v2.webp`: เวอร์ชันทดลองล่าสุดสำหรับงานร่วมบุญกับมหาบูตะ เปลี่ยนชุดตามภาพงานและเพิ่มฉากสวรรค์ ยังรอ feedback ผู้ใช้ ไม่ถือว่าอนุมัติรายละเอียดใหม่ทุกจุดแล้ว
- แสตมป์พิเศษ 2D เป็นอีกสายงานหนึ่ง ไม่ใช่เอาตรา 3D ไป flatten และไม่ใช้ภาพ 2D ชุดเดิมในเว็บเป็นแม่แบบที่ถูกต้องโดยอัตโนมัติ
- รุ่น `*-line-v1.webp` ถูกปฏิเสธเรื่องรูปทรงไดคัต: ผู้ใช้ต้องการดีไซน์แสตมป์เดิม เปลี่ยนเฉพาะลายเส้นด้านใน รุ่นแก้ `*-stamp-line-v2.webp` ทั้ง 5 ชนิด (dayone, lucky, tier, friend, first) รอ feedback รายละเอียดภาพ พรอมป์ต์อยู่ที่ `design-previews/passport-special-stamp-line-v2-prompts.md`

### ข้อกำหนดถาวรสำหรับแสตมป์พิเศษ 2D

- เป็นแสตมป์วงกลมขอบหยัก มีวงกรอบชั้นใน พื้นกระดาษสีงาช้าง และชื่อดวงตามแบบเดิม ห้ามเปลี่ยนเป็นสติกเกอร์ไดคัตตามตัวละคร
- ใช้ LINE เป็น reference เฉพาะลายเส้น สี และตัวตนของแมว ไม่คัดลอกรูปทรงสติกเกอร์หรือข้อความทักทายมาใช้
- ภาพตัวละครทั้งหมดอยู่ภายในกรอบ ด้านนอกโปร่งใสจริง ไม่มีเส้นขาวไดคัตรอบตัวแมว
- dayone: แมวทั้งสาม; lucky: โนบิกับไมค์; tier: บูตะไหว้กับดอกบัว; friend: โนบิต้อนรับ; first: ชิบะชุดฟ้า กรอบฟ้าแทนเขียว
- ชื่อภาษาอังกฤษประจำดวงคงอยู่ตามดีไซน์เดิมได้ แต่จำนวน รอบ และข้อมูลผู้ใช้ต้องเป็น dynamic text ใน UI/ภาพแชร์เสมอ
- ตรา 3D งานหลักเป็นคนละชุด ไม่เปลี่ยนกรอบหรือวัสดุตามงาน 2D นี้

ข้อสังเกตจากภาพต้นฉบับ (ไม่ใช่การวัดสีจากไฟล์ master):
- ลายเส้นเรียบโค้งมน น้ำหนักเส้นนุ่ม สีเส้นสัมพันธ์กับสีตัว ไม่ใช่เส้นดำหนาเท่ากันทั้งภาพ
- สีพื้นแบบ flat มีเงาเพียงเล็กน้อย ไม่มีผิวพลาสติกหรือแสงสตูดิโอแบบ 3D
- หัวใหญ่ ลำตัวและแขนขาสั้น ท่าทางอ่านได้เร็วที่ขนาดเล็ก
- โนบิ: ครีม ลายแท็บบีเบจทอง หน้าหวาน ขนตา ตาเป็นประกาย แก้มชมพู อารมณ์คาวาอี้ แสดงความรู้สึกได้มาก
- บูตะ: ตัวถ่านเทา อ้วนกลม แว่นวงกลมทอง ลายหน้าผากเทา พุงเทา ภาษาท่าทางขี้เล่น ต้นฉบับมีหลายสีหน้า แต่สำหรับ Passport ให้ยึดข้อกำหนดผู้ใช้เรื่องตา/ปากเดิมก่อน ไม่ใช้สีหน้าใหม่โดยไม่ได้ตกลง
- ดาว หัวใจ ขีดเคลื่อนไหว เป็น accent เล็ก ๆ ไม่แย่งหน้าคาแรกเตอร์
- ตัวหนังสือไทยในต้นฉบับให้ความรู้สึกเขียนมือ แต่ชื่อประเภท/จำนวน/วันที่ของ Passport ควรเป็นข้อความจริงใน UI เพื่อคมและเปลี่ยนตามข้อมูลได้

ก่อนผลิต 2D ใหม่ ให้หาไฟล์ master หรือดาวน์โหลดเฉพาะตัวอย่างที่เกี่ยวข้องจากชุดนี้เพื่อเปิดดูใกล้ ๆ อย่าอ้างอิงจากภาพ screenshot ย่อเพียงอย่างเดียว

## 3. กฎหน้าตาและสัดส่วนที่ต้องล็อก

- หัวกลมใหญ่ ตัวสั้นอ้วนตาม sheet ไม่ยืดแขนขาเป็นสัดส่วนมนุษย์
- บูตะ: แว่นทองกลม ตาดำกลมเดิม ปากเล็ก inverted-Y หน้านิ่ง ไม่เพิ่มยิ้ม คิ้วขาวหรือเทาอ่อน หนวดสองเส้นต่อข้าง ลายหน้าผากสามเส้น หูด้านในและอุ้งเท้าสีเทา
- โนบิ: ครีมทอง หน้าผากสามเส้น หนวดสองเส้นต่อข้าง ขนตา ตาดำและจมูกชมพู ชุดเดรสชมพู/โบว์ดอกไม้เมื่อใช้ชุดนี้
- ชิบะใช้ฟ้า/น้ำเงิน ไม่ใช้เขียว คิ้วเข้มตาม sheet
- มือมีสี่นิ้วเท่านั้น ตรวจนิ้วกับปุ่มอุ้งเท้าแยกกัน: ปุ่มกลางไม่ใช่นิ้ว ห้ามปล่อยข้อผิดพลาดจากภาพอ้างอิงตามมา
- หางหนึ่งเส้น ผอมกลม มีแถบสี อยู่ด้านหลัง ไม่เป็นพุ่มหรือโผล่สองข้างเหมือนสองหาง
- โนบิและชิบะมีลายสามเส้นที่แขนตาม sheet เมื่อบริเวณนั้นมองเห็น ไม่วาดลายบนฝ่ามือ
- เมื่อรายละเอียดมือไม่จำเป็น ใช้ภาพช่วงอกหรือท่าที่ไม่โชว์ฝ่ามือ เพื่อลดจุดผิดพลาด ไม่วาด anatomy ใหม่โดยเดา

## 4. Visual recipe — ตรา 3D Passport

- รูปสี่เหลี่ยมใกล้จัตุรัส ขอบหยักโค้งแบบ postage stamp; โลหะทอง champagne นูนและมีขอบด้านในอีกชั้น
- ตกแต่งมุมอย่างพอดี มี motif ของงานตรงล่างกลาง (เช่น ดอกบัว) ไม่เพิ่มลวดลายจนหน้าเล็ก
- วัสดุ porcelain enamel เนียนนูน ผิว satin มี specular คมบางจุด ไม่ใช่ plush/ขนฟู ไม่ใช่ 2D vector
- มองตรงด้านหน้า แกนตั้งตรง ภาพต้นฉบับไม่เอียง perspective; การเอียงเล็กน้อยและเงาวางบนกระดาษให้ CSS ทำ
- ตัวละครเป็นจุดหลัก ใบหน้าชัดที่ 120–164px ภาพ modal ชัดที่ 280px
- กรอบกินพื้นที่ประมาณ 88–92% ของ canvas เหลือขอบปลอดภัย 4–6% ไม่ตัดหู หมวก ปีก หรือคทา
- โทนอุ่น ivory/champagne; โนบิ blush, บูตะ lavender/charcoal, ชิบะ powder blue; ธีมบุญเพิ่มฟ้าอ่อนและทองได้
- พื้นนอกกรอบต้อง transparent alpha จริง ไม่มีสี่เหลี่ยมสีขาวหรือเงาฟุ้งด้านนอก
- ไม่มีชื่อ วันที่ จำนวน หมายเลข หรือโลโก้ที่ AI วาดฝังในภาพ ข้อมูลเหล่านี้อยู่ใน UI/Canvas เท่านั้น

## 5. มหาบูตะ / เข้าพรรษา — ข้อยกเว้นชุดเฉพาะงาน

ใช้ภาพ `merit-vassa-2026.webp`: แจ็กเก็ตขาวขอบทอง เสื้อกั๊กขาว กางเกงทองสั้น หมวกทรงกรวยลายขาวสลับทอง คทาดาว ปีกขาวเล็ก

เนื้อเรื่องภาพ: ลอยขึ้นบนเมฆมุก มีรัศมีแสงอุ่นและท้องฟ้าอ่อน ให้เป็นเทวดาน่ารักขึ้นสวรรค์ ไม่ใช่ภาพไว้อาลัย ไม่เปลี่ยนเป็นเทวดาตะวันตก ไม่ใช้สูทม่วงในตรางานนี้อีก

คงหน้า/ตา/ปากบูตะแบบตราเดิม ไม่ลอกตาประกายใหญ่จากโปสเตอร์หากทำให้ตัวตนเปลี่ยน ชุด/ฉากเปลี่ยนได้ แต่คาแรกเตอร์และกรอบต้องยังอยู่ใน collection เดียวกัน

## 6. Workflow ให้เหมือนคนวาดเดิม

1. อ่านคู่มือนี้และเปิดดูตราต้นแบบจริงทุกครั้ง อย่าสร้างจาก prompt ล้วน
2. แนบภาพตราที่อนุมัติเป็น edit target, แนบ sheet เป็น identity reference, แนบภาพงานเป็น outfit/story reference ระบุหน้าที่แต่ละภาพชัดเจน
3. แก้เพียงชุด/ท่า/ฉากที่จำเป็น คง shape กรอบ น้ำหนักทอง มุมกล้อง ผิว และหน้าตา
4. ทำหนึ่งตราต่อภาพ เก็บ PNG master และ prompt จาก built-in imagegen ไว้; ห้ามบีบรวมเป็น sprite sheet เพื่อลัดงาน
5. ตรวจภาพใหญ่และ thumbnail บนครีมกับพื้นเข้ม: ตา ปาก หนวด นิ้ว หู หาง สีประจำ กรอบไม่ขาด alpha ไม่มี halo ตัวอักษรหลง
6. ผิดเฉพาะจุดให้แก้จากภาพเดิมด้วยคำสั่งเฉพาะจุด ไม่เริ่มวาดใหม่ทุกครั้ง
7. export WebP 800px quality 90 รักษา alpha ใช้ชื่อมีเวอร์ชัน ห้ามลบ/ทับต้นแบบที่ผู้ใช้ชอบ
8. อัปเดต `src/lib/stamp-art.js` เฉพาะ path ของภาพ bundled ที่ต้องเปลี่ยน ไม่ override ภาพ custom ที่แอดมินอัปโหลด และไม่แก้สิทธิ์การได้แสตมป์
9. ตรวจทั้งสมุด, Modal, ภาพแชร์จาก `src/lib/passport-image.js`; ภาพตราสี่เหลี่ยมต้องไม่ถูก crop เป็นวงกลม
10. บันทึกว่าเวอร์ชันไหนรอ feedback กับเวอร์ชันไหนอนุมัติแล้ว ไม่ถือว่าภาพ generate ผ่านโดยอัตโนมัติ

## 7. Prompt template

Use case: precise-object-edit. Image 1 is the approved enamel stamp EDIT TARGET; image 2 is character identity reference; image 3 is event outfit/story reference. Preserve square scalloped champagne gold rim, inner border, camera, face identity, enamel relief and transparent outside background. Change only [outfit/pose/story]. Keep exact character anatomy and markings. No text/dates/logos; live UI handles these. Crisp frontal collectible, restrained satin porcelain, golden raised metal edges, clear thumbnail silhouette, 5% safe margin. Do not redesign the character or frame.
